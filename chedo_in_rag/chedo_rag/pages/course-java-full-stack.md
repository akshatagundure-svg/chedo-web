## Detailed 25-Module Roadmap

Review the full technical curriculum divided into 6 learning phases. Click on any module below to expand the list of topics and technologies.

## PHASE 1 — Java Foundation

MOD 01
Java Programming Foundation

▶

Core Java foundations and VM environment:

- Java Introduction & Syntax: Variables, Data Types, Operators, Input / Output

- Control Statements: if/else conditions, switch blocks, for/while loops, methods

- Type Casting, Wrapper Classes, Scanner class input operations

- Arrays, String manipulation methods, Packages configuration

- Debugging basics, Exception basics, File Handling fundamentals

- Understanding JVM: JDK, JRE, JVM architecture, Bytecode, Platform Independence

MOD 02
Object-Oriented Programming

▶

Professional Java architecture principles:

- Classes & Objects, Constructors, 'this' keyword usages

- Four Core Pillars: Encapsulation, Inheritance, Polymorphism, Abstraction

- Method Overloading & Method Overriding mechanisms

- Abstract Classes vs Interfaces, Access Modifiers, 'super' and 'final' keywords

- Static variables and methods, Anonymous Classes, Class structures in packages

MOD 03
Advanced & Modern Java

▶

Modern Java features and runtime memory internals:

- Collections Framework: List, ArrayList, LinkedList, Set, HashSet, Map, HashMap, Queue

- Sorting & Iteration: Iterator, Comparable, Comparator, Generics

- Modern Features: Lambda Expressions, Functional Interfaces, Stream API, Optional class, Date & Time API, Records

- Multithreading & Concurrency: Thread lifecycle, Synchronization, Executor framework, CompletableFuture, Virtual Threads

- Memory Internals: JVM fundamentals, Garbage Collection algorithms, Heap & Stack management

MOD 04
Data Structures & Algorithms

▶

Practical developer DSA and interview preparation:

- Linear Structures: Arrays, Strings, Linked Lists, Stack, Queue operations

- Non-Linear Structures: Trees (Binary Trees, BST), Graph fundamentals, Hash maps

- Searching & Sorting: Linear Search, Binary Search, Bubble, Selection, Insertion, Merge, Quick Sort

- Problem Solving: Recursion patterns, Time Complexity & Space Complexity (Big O) analysis

## PHASE 2 — Database & Web Foundation

MOD 05
SQL & Databases

▶

Relational databases, Document datastores, and Caching:

- MySQL & PostgreSQL: Tables, primary keys, foreign keys, relationships, database design

- SQL Statements: CRUD (SELECT, INSERT, UPDATE, DELETE), WHERE, ORDER BY, GROUP BY, aggregates, JOINs, subqueries

- Data Architecture: Database normalization (1NF, 2NF, 3NF), transactions, indexing

- MongoDB: Documents, collections, NoSQL CRUD operations, data modeling

- Caching Introduction: Redis key-value storage structures, caching concepts

MOD 06
JDBC + JPA + Hibernate

▶

Traditional Java connectivity to modern Object-Relational Mapping (ORM):

- JDBC: Architecture, Driver, Connection, Statement, PreparedStatement, ResultSet, CRUD with JDBC, transactions

- JPA & Hibernate ORM: Entities, lifecycle, Repositories, Primary key generation

- Mapping Relationships: OneToOne, OneToMany, ManyToOne, ManyToMany mappings

- Advanced ORM: JPQL, pagination, transactions, Lazy vs Eager loading concepts

MOD 07
Web Development Foundation

▶

Core web technologies and legacy Java Web servlet architectures:

- HTTP Protocol: HTTP/HTTPS methods, requests/responses, header fields, status codes

- Frontend Foundations: HTML5 semantics, CSS3 Flexbox & Grid layouts, responsive designs, Bootstrap

- JavaScript: DOM selectors, events, fetch calls, JSON structures, async/await, promises

- Java Web Legacy: Servlets, JSP, Session management, cookies, MVC web fundamentals

MOD 08
React Frontend Development

▶

Modern Single-Page Application (SPA) architecture in React:

- React Fundamentals: JSX, component structure, props, state

- React Hooks: useState, useEffect, functional lifecycle hooks

- Routing & Nav: React Router DOM configuration, protected routing layers

- API Integration: Consume REST APIs with Axios, configure authentication UI layers (login, dashboards)

## PHASE 3 — Spring Boot Backend

MOD 09
Spring Framework

▶

Core principles of Dependency Injection and modular architecture:

- Spring Core Architecture & Ecosystem: Inversion of Control (IoC), Dependency Injection (DI)

- Spring Beans: Configuration classes, Bean scopes, Component Scanning

- Annotations-based setup, Spring MVC architectures, Layered enterprise designs (Controller -> Service -> Repository)

MOD 10
Spring Boot (Flagship)

▶

Building production-grade microservices quickly:

- Spring Boot Project structure, starter dependencies, auto-configuration features

- Properties & YAML files, environment profiles, profile-specific configurations

- DTOs (Data Transfer Objects), validation annotations (JSR-383), global exception handlers

- Spring Boot Actuator endpoints, health checks, metrics, external variables injection

MOD 11
REST API Development (Flagship)

▶

Designing clean HTTP application interfaces:

- REST resource designs, endpoints naming, mapping methods (GET, POST, PUT, DELETE, PATCH)

- Query parameters, path variables, request bodies (JSON serialization)

- ResponseEntity wrappers, pagination, filtering, sorting operations

- API documentation with OpenAPI / Swagger UI tools, Postman validation suites

MOD 12
Spring Security & Authentication (Flagship)

▶

Securing your enterprise endpoints:

- Authentication & Authorization pipelines, custom Security Filter Chains

- User registrations, password hashing with BCrypt encoder

- Role-Based Access Control (RBAC) configurations

- JSON Web Token (JWT) architecture, token validation, secure keys storage, CORS & CSRF protection

MOD 13
Testing & Software Quality

▶

Writing high-quality test suites for Java systems:

- Unit Testing with JUnit and Mockito mocking framework

- Mocking repositories, testing services in isolation

- Controller layer testing with MockMvc, full integration test suites

- Code quality architectures: SOLID principles, clean code practices, Testcontainers foundations

MOD 14
Full Stack Integration

▶

Connecting React SPA with Spring Boot backend:

- Cross-Origin Resource Sharing (CORS) configurations in Spring Boot

- Consuming secure API endpoints in React, storing JWT tokens in memory/local storage

- Form handling: Sending JSON payloads, rendering server validations on HTML layers

- Implementing global features: Pagination, search filters, secure file uploads

## PHASE 4 — Enterprise Engineering

MOD 15
Microservices Architecture (Flagship)

▶

Decomposing monolith architectures into distributed services:

- Monolith vs Microservices patterns, database decomposition strategies

- Service Discovery with Netflix Eureka, routing requests with Spring Cloud Gateway

- Centralized configurations, Inter-service communication patterns (RestTemplate, WebClient)

- Fault Tolerance configurations: Resilience4j circuit breakers, retries, and rate limiters

MOD 16
Apache Kafka & Event-Driven Systems

▶

Asynchronous, decoupled event-based architectures:

- Event-driven architecture concepts, Producers, Consumers, Topics, and Partitions

- Consumer groups configurations, message deserialization patterns

- Building event-based microservices using Spring Boot Kafka interfaces

MOD 17
Redis & Performance

▶

Caching strategies to speed up database lookups:

- Redis caching: Key-value operations, Cache-Aside pattern implementation

- Session storage management, optimizing slow SQL queries with indexes and pagination

- Database connection pooling optimization concepts

MOD 18
System Design

▶

Designing scalable, highly-available enterprise systems:

- High-Level & Low-Level systems design, SOLID principles, common design patterns

- Scalability, availability, reliability targets, load balancing, database replication/sharding

- Real-World System Architectures: E-Commerce Platform, Chat Application, Student Portals

## PHASE 5 — DevOps & Cloud Deployment

MOD 19
Git, GitHub & Build Tools

▶

Build lifecycle management and collaborative version control:

- Git Version Control: commits, branching, merging, conflict resolution

- GitHub collaboration workflows, pull requests, code review pipelines

- Maven: pom.xml structures, build lifecycles, packages, dependency configurations

MOD 20
Docker & Containerization

▶

Packaging applications for consistent execution environments:

- Containerization fundamentals: writing Dockerfiles, compiling image layers

- Ports mapping, Docker volumes for data persistency, networking containers

- Docker Compose: Building multi-container configurations (React + Spring Boot + DB + Redis)

MOD 21
Kubernetes Fundamentals

▶

Orchestrating containerized systems at scale:

- Container orchestration basics, Kubernetes architectures, Clusters, Nodes, and Pods

- Kubernetes Deployments, services configurations, ConfigMaps, secrets inputs

- Scaling deployments, basic health checks, container orchestrations

MOD 22
CI/CD & DevOps

▶

Automating the delivery pipeline from code check-in to deployment:

- CI/CD fundamentals: continuous integration, automated test runners

- GitHub Actions: writing workflow YAML scripts, packaging Docker images automatically

- Managing isolated environments: Development, Testing, Staging, and Production

MOD 23
Cloud Deployment

▶

Publishing Java applications onto public cloud nodes:

- Cloud compute systems (AWS EC2 / GCP Compute Engine basics), managed datastores

- Containerized application deployments, loading variables, DNS bindings, HTTPS configurations

MOD 24
Observability & Production Readiness

▶

Monitoring application health post-deployment:

- Production logging, metrics collection with Actuator, Distributed tracing basics

- Observability pillars: Logs + Metrics + Tracing configurations, troubleshooting techniques

## PHASE 6 — Modern AI & Capstone

MOD 25
AI-Enabled Java Applications (Flagship)

▶

Integrating LLMs and semantic database searches in Spring Boot:

- LLM API integrations, structured AI outputs, prompt construction

- Spring AI Framework: Connectors, configuring vector indexing (Vector search)

- RAG integrations in Java applications: Document loaders, injecting context into LLM queries

- AI Agent concepts, Tool/Function calling from Java application layers
