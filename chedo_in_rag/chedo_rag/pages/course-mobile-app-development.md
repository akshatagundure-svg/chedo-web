// COURSE OVERVIEW

## About This Course

This 12-week program teaches mobile app development with Flutter and Dart — one codebase that runs on Android, iOS and the web. You start with Dart basics and Flutter widgets, then work through navigation, state management, local storage, authentication, APIs, backend integration and deployment.
The course is practical from week one: five projects during the course plus one real-time project, using Firebase services (Authentication, Firestore, Storage and Realtime Database), SQLite, Hive and REST APIs.
Note: this syllabus is a general outline and may be adjusted based on class progress and individual student needs.
