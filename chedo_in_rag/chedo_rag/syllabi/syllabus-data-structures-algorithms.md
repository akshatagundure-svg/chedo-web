## About This Course

Data Structures & Algorithms is the subject that turns code into efficient software — and the foundation of technical interviews. This course covers the full spectrum: from arrays and linked lists to stacks, queues, searching, sorting, trees and graphs.
Each structure is studied in depth — including advanced variants like circular and double-ended queues, AVL, red-black and B-trees, and graph algorithms like Dijkstra's and Floyd-Warshall — with implementations practiced in class.

// PROJECTS

## Projects You Will Build

Course projects are the point — working software you finish, run, and keep. (Note: These are independent capstone projects, distinct from classroom exercises).

## Dynamic Array (Vector)

Implement a self-resizing dynamic array (vector) with manual memory allocate, push, pop, insert, and resizing bounds.

## Linked List Nodes

Create a full Singly & Doubly Linked List library with insertion, nodes traversal, deletion, and fast/slow cycle pointers.

## Custom Stack & Queue

Build custom container stacks and queues using arrays and list pointers, handling memory overflow bounds.

## Binary Search Tree (BST)

Implement a standard BST with manual insertion, nodes deletion, element query search, and recursive traversals.

## Heap Structures

Develop Min/Max heap models using array representations with heapify transformations and priority selection algorithms.

## Hash Table & Graph Models

Implement custom Hash Tables with chaining collisions and build Adjacency List graph representations to run BFS/DFS paths.
