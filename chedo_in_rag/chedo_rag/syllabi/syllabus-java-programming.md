// COURSE OVERVIEW

## About This Course

Java is one of the most widely used languages in the world, and this course builds its foundations properly: syntax, operators, control flow, strings, methods, constructors and static features first — then the OOP core of Java: inheritance, abstraction, polymorphism, interfaces, packages and access control.
You also get exception handling, GUI programming with Applets and AWT (including event handling), file handling and sorting algorithms — taught offline with live coding and practice programs at every step.
