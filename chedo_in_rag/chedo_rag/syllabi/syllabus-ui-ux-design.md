// COURSE OVERVIEW

## About This Course

This course builds a complete modern design toolkit: Canva for fast visual assets, Figma for interface design and prototyping, Adobe Photoshop for image work, CorelDRAW for vector graphics, and AI design tools for generative workflows.
Beyond the tools, you learn branding and visual identity — logos, typography, color systems and brand kits — plus documentation and design systems: style guides, UI kits, component libraries and developer hand-off. Everything is hands-on and project-driven.
