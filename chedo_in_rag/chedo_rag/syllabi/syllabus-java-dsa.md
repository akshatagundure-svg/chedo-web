##
Course Curriculum Modules

Explore our structured phases below, going from zero Java compilation to advanced coding structures.

PHASE 1

## Java Foundation

JVM/JRE/JDK models, byte compiling, control flow loops, standard arrays, logic rules

## Java Virtual Machine & Setup

- • JDK vs JRE vs JVM architectures

- • Bytecode compiling & standard variables

- • Primitive data types & type casting operations

- • Operators, standard input/output streams

## Logic Building & Core Structures

- • Conditions (if/else, switch case controls)

- • Loops (while, for, do-while), break/continue statements

- • Logic methods, parameter passing, return structures

- • Standard 1D & 2D arrays, Java string buffers

- • Exception fundamentals, wrapper classes, debugging

PHASE 2

## Object-Oriented Java

Classes, Access Modifiers, Constructor lifecycles, polymorphism, abstraction

## Classes & Inheritance

- • Classes, objects, memory allocations

- • Constructors (default, parameterized), lifecycle controls

- • this & super reference keywords

- • Encapsulation (getters/setters), access modifiers

- • Single, multilevel, and hierarchical inheritance

## Polymorphism & Abstraction

- • Method overloading & overriding behaviors

- • Abstraction models: Abstract classes vs Interfaces

- • Static fields, final variables, object lifespans

PHASE 3

## Advanced Java + Collections

Generics, exception pipelines, List, Set, Map, Queue, Comparators

## Advanced Java Essentials

- • Try-catch-finally block exception pipelines

- • Java Generics (classes, methods, constraints)

- • Enums, Lambdas, Functional Interfaces

- • Java Stream API, filter/map pipelines, Optional

## Collections Framework

- • List interface: ArrayList vs LinkedList

- • Set interface: HashSet, LinkedHashSet, TreeSet

- • Map interface: HashMap, LinkedHashMap, TreeMap

- • Queue interface: ArrayDeque, PriorityQueue

- • Comparable vs Comparator sorting interfaces

PHASE 4

## DSA Foundation

Time & Space complexities, Big-O metrics, worst/best cases

- • Introduction to algorithms & performance trade-offs

- • Big-O notations: O(1), O(log n), O(n), O(n log n), O(n²)

- • Best, Average, and Worst case runtimes

- • Memory stack space vs heap allocation tracking

PHASE 5

## Linear Data Structures

Custom nodes, arrays, linked lists, stacks, queues, hash maps

## Arrays, Strings & Lists

- • Array matrix operations, searching, prefix sum grids

- • Two Pointers, Sliding Window limits

- • Manual Singly, Doubly, and Circular Linked Lists

- • Cycle detection (Floyd's algorithm), list reversal

## Stacks, Queues & Hashing

- • Custom stacks, monotonic array checks, postfix expression parsers

- • Custom queues, circular implementations, Priority Queue

- • Hashing functions, hash tables, collision models

PHASE 6

## Algorithms

Linear & Binary searches, divide-and-conquer sorting, recursion trees, backtracking

## Searching & Sorting

- • Binary Search on sorted ranges, boundaries

- • Bubble, Selection, and Insertion Sorts

- • Merge Sort & Quick Sort recursion structures

- • Heap Sort, Counting Sort concepts

## Recursion & Backtracking

- • Base cases, recursion stack tracking

- • Subsets & permutations generation

- • Backtracking: Sudoku solver, Rat in a Maze

PHASE 7

## Trees + Graphs

BST nodes, level order traversals, AVL trees, Adjacency Lists, BFS, DFS, Dijkstra

## Hierarchical Trees

- • Binary trees, inorder/preorder/postorder recursive traversals

- • Binary Search Trees (BST): searches, insertions, deletions

- • Balanced tree concepts: AVL structures, self balancing trees

- • Priority Queue heap arrays, Top-K items

## Network Graphs

- • Adjacency matrix, adjacency list representations

- • BFS & DFS traversals, cycle detection

- • Topological sorting, connected component analysis

- • Pathfinding: Dijkstra, Kruskal, Prim, Bellman-Ford

PHASE 8

## Advanced Problem Solving

Greedy strategy, Dynamic Programming, memoization states, tabulation charts

## Greedy & Optimization

- • Greedy strategies, fractional knapsack pipelines

- • Job scheduling, interval overlays

## Dynamic Programming

- • Memoization (top-down) vs Tabulation (bottom-up)

- • Classic DP: Climbing stairs, Coin change, LCS, LIS

- • Derive state transitions and base boundaries

PHASE 9

## Interview Preparation

Pattern matching (Two Pointers, Sliding Window, Counter), Java Q&A, dry runs

## Pattern Solving Framework

- • Pattern matching: Sliding Window, Prefix Sum, Two Pointers

- • Monotonic Stacks, Fast/Slow pointers, BFS/DFS networks

- • Constraint validation → Pattern matching → Complexity optimization

## Java Technical Q&A

- • JVM memory segments, garbage collection policies

- • Overloading vs Overriding runtime differences

- • ArrayList vs LinkedList internal layouts

- • HashMap hash codes, collisions, bucket tree conversions

- • Comparable vs Comparator implementations
