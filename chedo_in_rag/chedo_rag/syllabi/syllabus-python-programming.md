## About This Course

Python is the language of data, automation and modern scripting — and a great first language because you can see results quickly. This course covers everything from data types and control structures to lists, tuples, sets, dictionaries, functions, modules, recursion and OOP.
File handling and exception handling complete the picture, and every topic is practiced with programs in our offline classroom format.
