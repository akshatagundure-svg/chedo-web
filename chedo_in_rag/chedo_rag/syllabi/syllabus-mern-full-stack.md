Syllabus Breakdown

## Detailed 36-Module Roadmap

Review the full technical curriculum divided into 10 learning phases. Click on any module below to expand the list of topics and technologies.

## PHASE 1 — Web & Programming Foundation

MOD 01
HTML5 & Modern Web Foundation

▶

How the web works and HTML5 semantic structures:

- Client / Server Architecture, Browser internals

- HTTP / HTTPS protocols, semantic tags structure

- Forms, inputs types, validations, accessibility (A11y) basics, SEO tag architectures

MOD 02
CSS3 & Responsive UI Development

▶

Modern styling systems and layout engines:

- CSS fundamentals, Box Model, positions, Flexbox and CSS Grid

- Responsive Design: mobile-first media queries, transitions, variables

- Framework exposure: Bootstrap layouts, Tailwind CSS basics

MOD 03
JavaScript Programming

▶

Logic building and scripting fundamentals:

- Variables (let/const), primitive types, execution loops, control logic

- Functions structures, scope chains, closure architectures

- Arrays, objects, error try-catch blocks, JSON format, DevTools debugging

MOD 04
Modern JavaScript ES6+

▶

Advanced JS capabilities and runtime patterns:

- Arrow functions, destructuring, spread & rest parameters

- Advanced iteration: map, filter, reduce, find, execution pipelines

- ES modules, Classes constructs, promises and async/await syntax patterns

MOD 05
DOM & Browser Programming

▶

Interacting with visual browser viewports:

- Selecting, updating, inserting HTML elements

- Event binding listeners, event bubbling, event delegation layers

- Form states validations, local storage, session storage data retention

MOD 06
APIs, Async JavaScript & HTTP

▶

HTTP communication layers and data fetching:

- Client/Server pipelines: HTTP requests, response configurations, methods (GET, POST, etc.)

- Status codes mapping, consuming public REST APIs with native fetch, async/await pipelines

- Managing loading states, network error catches, and handling CORS headers

## PHASE 2 — Modern Frontend Engineering

MOD 07
TypeScript

▶

Type-safe JS web application development:

- Type inference, variables casting, interfaces setups, type aliases

- Union types, function type safety, generics fundamentals

- Configuring TS modules inside React client folders and Node.js servers

MOD 08
React Fundamentals

▶

Building component-driven user interfaces:

- React project directories, JSX parser rules, functional components

- Props arguments rendering, state logic binds, listing rendering, conditional visual returns

- Controlled inputs, form tracking layers, React DevTools inspections

MOD 09
React Hooks & Application Architecture

▶

Component state synchronization and architectural flows:

- Core hooks: useState, useEffect runtime triggers, useRef bounds

- useMemo and useCallback optimizations patterns, building custom state hooks

- Context API setups to prevent deep prop drilling pipelines

MOD 10
React Routing & State Management

▶

Client routing layers and state management libraries:

- React Router DOM setup, dynamic parameters paths, nested layout views

- Protected routes guards, redirect routes for unauthorized views

- Global state libraries: Redux Toolkit (RTK) actions, reducers, store maps

MOD 11
Professional Frontend Development

▶

Connecting APIs to feature-rich React interfaces:

- Consuming secure API structures, JWT authentication flows storage

- Forms validation inputs, searching queries, pagination UI structures

- UX features: Loading skeletons, tables, modal structures, performance code splitting

MOD 12
Next.js Exposure

▶

Modern meta-frameworks and server rendering options:

- Next.js file routing, layout wrappers, Server vs Client component architectures

- Introduction to Server-Side Rendering (SSR) & Static Site Generation (SSG) concepts

## PHASE 3 — Backend Engineering

MOD 13
Node.js

▶

Event-driven, asynchronous server environments:

- Node.js runtime environment, package management (npm), CommonJS vs ES Modules

- Core built-in modules: File system commands, Paths, variables inputs

- Event Loop internals, asynchronous operations, event emitters, streams concepts

MOD 14
Express.js

▶

Modular web API serving frameworks:

- Express setup, routing controllers, middleware configurations

- Handling request arguments, query variables, parsing bodies (JSON)

- Custom error handlers, folder architecture patterns (MVC, routing files separators)

MOD 15
REST API Engineering

▶

Designing scalable HTTP interfaces:

- REST resource structure guidelines, method codes (GET, POST, etc.)

- Payload structures, input validators, modular controllers structures

- Exposing pagination variables, search query bindings, API metrics checks

## PHASE 4 — Databases & Data Layer

MOD 16
MongoDB

▶

NoSQL collections, document models, and operations:

- MongoDB basics, BSON schemas, documents queries filters

- Embedded schemas, collection references structures, query indexing optimizations

- Aggregation pipelines: stage operations, projections, lookups, datasets formats

MOD 17
Mongoose

▶

Object Data Modeling (ODM) inside Node.js applications:

- Defining Mongoose schemas and models, hooks/middlewares, validations

- Population commands logic, repository pattern structures inside Express servers

MOD 18
SQL & PostgreSQL Exposure

▶

Relational data models and SQL operations:

- PostgreSQL, table normalization schemas, SQL CRUD queries

- Comparing Document databases (MongoDB) vs Relational structures (Postgres)

MOD 19
Redis & Caching

▶

Key-Value caching patterns to optimize execution speeds:

- Redis caching setup, Cache-Aside pattern logic, TTL expiration bindings

## PHASE 5 — Security & Full Stack Development

MOD 20
Authentication & Authorization

▶

Securing endpoint access inside modern web applications:

- Password hashing via bcrypt, authentication checks with JSON Web Tokens (JWT)

- HTTP-only cookies data transit, Role-Based Access Control (RBAC) middleware

MOD 21
Web Application Security

▶

Sanitizing inputs and guarding against typical exploit vectors:

- Input validation logic, CORS mappings configurations, brute force rate limiters

- Awareness guidelines: XSS injection, CSRF attacks, NoSQL injection patterns

MOD 22
Full Stack Integration

▶

Connecting Express databases APIs with React SPA client engines:

- JSON data mapping configurations, routing login tokens flows

- Multi-feature UI panels: pagination, file upload endpoints, loading states

## PHASE 6 — Real-Time & Advanced Backend

MOD 23
Real-Time Applications

▶

Decoupled socket structures for fast, bidirectional updates:

- WebSocket fundamentals, Socket.IO channels configurations, event listeners

- Room groupings configurations, messaging pipelines, real-time update dashboards

MOD 24
Background Jobs & Application Workflows

▶

Asynchronous task runs outside standard request cycles:

- Node Cron jobs setups, email generation tasks, handling background task queues

MOD 25
File & Media Management

▶

Serving and processing custom multi-part file payloads:

- Multipart forms processing (Multer), file validation algorithms, cloud storage APIs (Cloudinary)

## PHASE 7 — Testing & Software Engineering

MOD 26
Testing

▶

Validating client components and server REST APIs:

- Jest fundamentals, unit testing server modules, mock assertions libraries

- API endpoint testing (Supertest), UI layout assertions (React Testing Library)

MOD 27
Clean Code & Software Architecture

▶

Structuring clean, maintainable JS/TS folder layouts:

- Separation of concerns (DRY), controller-service design architectures, SOLID principles

MOD 28
Git & GitHub

▶

Git configuration and PR collaborative workflows:

- Commit bounds, branches setups, resolving merge conflicts, configuring README portfolios files

## PHASE 8 — System Design & Scalability

MOD 29
System Design Fundamentals

▶

Designing scalable client-server architectures:

- Horizontal vs Vertical scaling guidelines, load balancers configurations

- Index constraints, pagination setups, rate limiters, database replica systems

MOD 30
Monolith & Microservices Concepts

▶

Architectural patterns overview for system architecture awareness:

- Monolith builds vs Microservices separations, service directories, and central API gateways

## PHASE 9 — DevOps & Deployment

MOD 31
Docker

▶

Packaging application stacks inside isolated containers:

- Container structures, writing Dockerfiles, Docker Compose multi-containers orchestrations

MOD 32
CI/CD

▶

Continuous validation and deployment pipelines:

- GitHub Actions configurations, environment variables inputs, secrets management

MOD 33
Cloud & Production Deployment

▶

Hosting databases, frontends, and API servers:

- Deploying static React client folder (Vercel) and Express API container nodes (Render)

- DNS mapping properties, SSL certificates bindings setups, Atlas database setups

MOD 34
Observability & Production Readiness

▶

Post-deployment monitoring and metrics tracking:

- Production logging, metrics collection (Response times, Error rates), health checks

## PHASE 10 — AI-Powered Web Development

MOD 35
AI Integration for Full Stack Developers (Flagship)

▶

Consuming LLMs and structured AI payloads inside web applications:

- LLM API connectivity inside Node.js, prompt configurations, streaming tokens data

- Structured JSON returns from LLMs, rendering AI chat layouts in React viewports

MOD 36
RAG & AI Application Concepts (Flagship)

▶

Connecting custom files to LLM contexts (RAG):

- RAG logic: document loading, chunking variables, embedding indexes, semantic search

- Supabase pgvector / ChromaDB database basics, similarity score mapping
