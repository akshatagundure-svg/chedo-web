Python Programming Foundation

- Object-Oriented Programming: Classes & Objects, Constructors, Inheritance, Encapsulation, Polymorphism

- Regression Analysis: Mathematical foundations

- Dimensionality Reduction and Time-Series Fundamentals

Machine Learning (Flagship)

▶

Our core machine learning curriculum:

- Supervised Learning: Linear Regression, Logistic Regression, Decision Trees, Random Forests, KNN, Support Vector Machines (SVM)

- Unsupervised Learning: K-Means, Hierarchical Clustering, PCA (Dimensionality Reduction), Pattern Discovery

- ML Engineering Workflow: Dataset Preparation, Feature Engineering, Feature Selection, Train/Test Splits, Cross Validation

- API Development: Structured JSON outputs, Function calling & Tool calling

- Multimodal models & API Integration

Embeddings & Vector Databases

▶

Storing and retrieving dense vector representations:

- Text embeddings & vector space representations

- Similarity Search: Cosine Similarity, dot product, L2 distance

- Document Chunking: Character chunking, recursive, token-based split, metadata tagging

- Vector indexing, storage, and retrieval workflows

- Vector Databases: ChromaDB, FAISS local indices, Supabase (pgvector), Pinecone concepts

MOD 11
Retrieval-Augmented Generation — RAG (Flagship)

▶

Connecting LLMs to corporate and custom documents:

- RAG Architecture: Document Loaders (PDFs, Docx, HTML, CSVs, Web scraping)

- Advanced Chunking, embedding, vector storage, and retriever setups

- Context Injection, Prompt construction, and LLM text generation

- Advanced RAG: Metadata filtering, hybrid search (keyword + vector), Reranking models (Cohere rerank)

- Implementing Conversation Memory for multi-turn chat assistants

- RAG Evaluation frameworks & minimizing model hallucinations

LangChain
Vector Search

MOD 12
Model Training & Fine-Tuning (Flagship)

▶

When to use Prompt Engineering, RAG, or Fine-Tuning:

- Model Training basics: Datasets (Train, Val, Test split), loss functions, optimizers, batch size, learning rate, epochs, overfitting, underfitting, model checkpoints

- LLM Fine-Tuning: Supervised Fine-Tuning (SFT), Instruction Datasets formatting

- Parameter-Efficient Fine-Tuning (PEFT): LoRA (Low-Rank Adaptation), QLoRA (Quantized LoRA)

- Model quantization: FP16, INT8, INT4 loading to run models on standard GPU hardware

- Evaluating fine-tuned models & Hugging Face weights deployment

- Structured output generation & Human-in-the-Loop approval setups

- Multi-agent communication structures

- Framework Exposure: LangChain Agents, LangGraph stateful loops, LlamaIndex workflows
